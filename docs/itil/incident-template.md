# Incident Record Template (ITIL-aligned)

| Field | Value |
|---|---|
| Incident ID | INC-YYYYMMDD-### |
| Logged by / time | |
| Reporter (name, dept, contact) | |
| Category | Hardware / OS / M365 / Network / Printer / Access / Other |
| Affected CI (asset tag / hostname / port) | |
| Impact | 1-High (dept/floor) · 2-Med (several users) · 3-Low (single user) |
| Urgency | 1-High · 2-Med · 3-Low |
| Priority | Impact × Urgency → P1 / P2 / P3 / P4 |

(What the user sees, error text, when it started, what changed)

|---|---|---|

## Resolution
